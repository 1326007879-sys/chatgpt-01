# 键盘语音、统一语言与动画扩充

日期：2026-11-09。用户授权三步依次开发；不自动发布。

## 1. 键盘语音输入

移除应用发起的 RecognizerIntent 及识别服务查询，不申请录音权限。
聊天框继续使用普通可编辑文本字段；用户通过所选手机输入法的麦克风听写，核对后手动发送。
输入框获得焦点时停止本应用的回复朗读。文字输入、发送、停止生成、重试及 TTS 设置保留。
输入法的语言、网络和语音服务由输入法管理，不能保证所有输入法均提供语音，也不能由本应用修复第三方语音服务。

## 2. 应用语言

默认简体中文，首页提供简体中文 / English 切换，设置独立持久化。
三个 Activity 使用同一个语言配置；主页面切换后重建，返回其他页面时核对语言并重建。
聊天草稿仍由应用级 ChatInputController 持有，不因页面重建而主动清除。
模型编辑弹窗未保存的编辑内容不跨重建保存，密钥也不写入 Activity 保存状态。
聊天、模型配置、语音设置、插件页、悬浮菜单与通知使用同一语言；动画名提供中英文。
悬浮服务监听语言变更，关闭旧菜单并刷新通知及无障碍名称，不重启桌宠。
资源缓存只在语言或设备配置改变时失效，避免每一帧创建新的 Context。
用户文字、历史消息、模型回复、用户自定义台词、第三方音色名称不自动翻译；系统输入法及系统设置语言由系统管理。

## 3. 动画三批扩充

来源为原作者 https://github.com/MerZlin/dsh-pet-indesktop，固定提交
`34d810b1eadd98d00e7cb9b3b51428a45b5bf03e`。
106 段源文件逐项核对；构建清单记录文件 SHA256、英文名和批次，不修改原始美术素材。

- 原核心：11 段。
- 第一批：12 段常用随机动作，包括写代码、睡觉、吃午餐、宅舞、玩魔方、三球抛接、五子棋、打哈欠、堆雪人、撸猫、照镜子、玩游戏。
- 第二批：其余 77 段随机动作，含节日和其他生活动作。
- 第三批：6 段余额事件动画，仅手动播放，不读取余额、不接入金融服务。

全部新增动作名称见 [动画清单](../ANIMATION_CATALOG.md)。

默认构建包含全部 106 段；可用 `-PpetAnimationBatch=0/1/2/3` 分别构建
11 / 23 / 100 / 106 段，用于分批验收及比较安装体积。并非应用内下载开关。
构建校验源文件身份，转换沿用无损透明帧流程；导出支持 random 和 events/balance。
动作菜单按批次分组并显示总数，点击一次播放，结束恢复待机；原有拖动、碰撞和暂停优先级保留。
同步原作者text_clips.json中的6个含字动作标记，转向时不镜像这些动画，避免字迹反转。
不预热全部新增动画，帧解码仍采用原有 24 MiB 缓存预算。

自定义导入和插件管理仍是预备入口。本轮不实现外置素材包安装、自动节日触发或记忆插件。
