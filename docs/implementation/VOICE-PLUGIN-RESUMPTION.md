## 提醒故障诊断

现有实现保存独立提醒记录并注册单次 AlarmManager 唤醒；允许精确权限时使用 setExactAndAllowWhileIdle，否则降级 setAndAllowWhileIdle。近似调度可能延迟，不能据此确认用户故障原因。

新增不含提醒正文、密钥或参考录音的本地诊断时间：成功注册的下一次调度、最近接收器唤醒、最近通知提交。提醒页展示记录。通知提交不等于用户看到或听到。记录属于尽力诊断，不代替持久化提醒记录；SharedPreferences 异步落盘可能在进程突然退出时缺失最近记录。

## 音色引擎接入约束

选型必须先通过未见文本、中文多音字、数字、长句、停止/取消与音色一致性验证，并记录安卓机型/API、冷启动、首句延迟、RAM、存储和发热。Linux 数值单独列出。

采用独立引擎 APK 与共享底座模型；音色包必须声明格式版本、引擎及模型兼容版本、文件清单、校验值、许可与来源。导入限制体积、文件数、路径和可接受格式，不加载任意代码，不重复打包每个音色的底座模型。

语音协议独立于现有仅文本插件 v1：宿主显式选择并授权引擎，绑定具体组件及签名身份；仅向引擎发送本次合成文本及选定音色，不提供模型密钥或完整聊天历史。合成任务需要请求标识、取消、超时、进程死亡处理和有界音频传输。引擎失效时显示原因，保留文字和通知，不静默冒用系统 TTS 声称目标音色成功。

聊天与提醒共享宿主音频播放/音频焦点与取消逻辑；提醒通知独立于语音成功。继续保留锁屏、静音、勿扰时的自动播报限制。
