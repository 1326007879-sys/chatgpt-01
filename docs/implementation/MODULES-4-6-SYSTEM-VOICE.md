# 模块4–6：语音输入、系统朗读与音色选择

日期：2026-11-09；分支：feat/android-next-update。用户授权三项一起执行，完成后统一汇报，不自动发布。

## 模块4：语音输入

聊天输入框上方“语音输入”调用设备已安装的识别Activity，优先请求中文、尽量离线；服务可能忽略离线请求并联网处理，不能承诺离线。输入提示中说明该情况。

识别结果追加到当前草稿，由用户编辑并点击发送；不会自动发起模型请求。取消或失败不清空草稿；合并后超过12,000字符时拒绝覆盖并提示。调用识别前停止TTS，避免录入朗读声。

使用外部识别Activity，麦克风权限由所选服务处理；本应用不直接录音，不新增RECORD_AUDIO权限，不保存音频。没有识别服务时显示提示并保留键盘输入。Android包可见性仅声明识别Activity与TTS服务查询，不请求查询所有应用。

## 模块5：回复朗读

已完成的助手回复提供“朗读”按钮和停止控制。语音设置中的自动朗读默认关闭；开启后仅在前台聊天页朗读新完成回复，不读用户消息、历史或取消/失败/中断回复。不在模型设置或语音设置页自动朗读。

回复完成后才朗读，不逐token朗读。长文本按系统TTS单次长度限制分段，保留UTF-16代理对；新播放替换旧队列。发送、重试、停止生成、打开设置时停止当前朗读；页面进入后台、退出或旋转销毁时停止并释放，回来不补播。

音频焦点丢失时停止。回调只接受当前批次；旧批次的完成、失败、停止或焦点回调不会中止新播放。结束时释放焦点，销毁时关闭TTS实例。

## 模块6：音色选择

聊天页“语音设置”展示当前默认系统TTS引擎返回的已安装音色、语言及联网标记；支持固定示例试听、停止、选择系统默认（中文）及具体音色。设置在本机持久化，音色按引擎名和音色名关联；引擎变化或音色移除时回退默认并提示。

没有引擎或中文语音时保留文字聊天并提示安装语言数据；可选择其它已安装音色，但中文朗读效果由引擎决定。选择即时保存，保存失败显示错误，不假装已保存。系统引擎可能联网处理朗读文字；不向引擎提供模型API Key。
