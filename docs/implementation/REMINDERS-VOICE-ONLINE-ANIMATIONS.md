# 提醒、语音播报与在线动画开发记录（未发布）

本轮用户允许连续完成剩余模块，普通实现和排错自主进行；只有必须介入的重大问题才暂停。不发布Release、不合入main、不修改云环境。

## 用户入口与数据范围

- 首页“便签与提醒”：创建独立提醒；插件查询/新增返回的记录下方“为此记录设置提醒”：以记录文本创建提醒。
- 提醒数据为明文JSON，独立于便签，保存在主应用noBackupFilesDir/reminders/items.json。删除便签不删除提醒，页面明确提示；用户可在提醒列表编辑、取消并删除。插件关联提醒绑定宿主保存的组件+授权指纹，插件停用、卸载或版本/签名变化后撤销；不依赖插件自己的后台进程。
- 插件内部单方面撤销配对不一定能被宿主主动感知；宿主的提醒授权和副本文本独立保存。若要撤销提醒，应在宿主停用插件或取消提醒。
- 不开放外部Binder提醒权限，不改变旧协议v1的权限范围。创建和确认发生在宿主私有Activity；插件没有获得通知权限、模型凭据或聊天历史。

## 调度与通知

支持一次性、每天重复，用户填写日期、24小时制时间，固定记录当前/原时区。首个时间必须在未来；夏令时规则沿用模块1。

使用唯一AlarmManager最近唤醒，不采用常驻轮询。用户允许SCHEDULE_EXACT_ALARM时使用精确调度，否则降级为近似时间。界面显示真实模式，并提供通知权限和精确闹钟设置入口。通知权限是保存入口前提，但系统仍可随时撤销。

BOOT_COMPLETED、MY_PACKAGE_REPLACED、TIME_SET、TIMEZONE_CHANGED、精确闹钟授权、插件移除/更新时重建调度并核对授权。通知发送失败不消费事件，安排15分钟后恢复尝试并显示错误；强制停止应用后需用户重新打开，不能承诺绕过系统或品牌省电限制。

迟到超过15分钟显示“错过的提醒”，不自动朗读；每天重复只处理一次积压，不连续补播过去多天。稳定通知tag和onlyAlertOnce避免重复提示，但进程在系统通知成功、持久化确认之前死亡时仍可能重试，不承诺跨崩溃恰好投递一次。

## 语音

独立、短时mediaPlayback前台服务，具有可停止的播放通知。语音接口ReminderVoiceProvider与当前SystemReminderVoice实现分开，后续可加入有独立授权的音色插件适配器。本轮不训练模型，不下载音色模型，不自动加载第三方组件。

使用聊天设置中已选的系统TTS音色；音色可能需要联网，依赖设备语音数据。提醒是否自动播报单独选择，默认关闭。后台启动限制可能阻止自动播放，文字通知仍有用户主动点击的“朗读提醒”。自动播放受锁屏、静音和勿扰规则限制，不绕过音频焦点。多个提醒排队播放；编辑、取消或授权撤销时使旧generation失效并停止现有提醒播报。

语音是尽力而为的附加提示，文字通知与语音失败隔离，不把声音当作唯一提醒。服务与聊天共用系统音频焦点；不混合同时输出。

## 在线动画

动画管理→在线动画，使用已经公开的preview.3固定目录与95个独立动作包。内置仅约40KB目录，不自动安装素材。显示中英文名称、大小、已安装状态，可多选、查看总下载量、逐个安装、取消和重试失败项。成功项保留，不因另一项失败回滚全部。

目录刷新必须匹配内置发布目录SHA256；这是一份固定版本目录，不是可任意更新的在线市场。未来新增官方动作需发布更新后的可信目录/客户端。保留本地SAF导入。

下载使用独立OkHttp客户端，不共享模型认证、Cookie或服务地址。仅HTTPS github.com和release-assets.githubusercontent.com的受控重定向，限制跳转数、超时、字节数；整包SHA256、目录ID/版本、逐帧哈希及WebP实际解码全部通过后才提交。错误ID/版本在安装事务内被拒绝，不能先安装后撤销。

必须停止悬浮桌宠才能安装，继续使用原有素材读写租约。下载时若另一路启动桌宠，最终安装仍由存储层拒绝，不能覆盖正在播放的文件。临时下载位于cacheDir，正常失败/取消后删除；进程异常终止的遗留缓存可能由系统回收。每次完整重试，不支持断点续传；素材压缩格式不变。

## 验证边界

编译、JVM、lint、APK构建与线上文件校验分别记录，不能替代设备验收。设备测试新增ReminderDeliveryDeviceTest，验证私有组件、真实通知和取消清理；必须在专用测试设备上执行。本轮在无KVM的官方API35模拟器中采用只读、2核/2GiB运行，约288秒确认启动稳定。首次安装响应超过120秒，随后确认实际已安装；最终构建重新安装主包和测试包均返回Success。5项最终设备用例全部通过（无忽略），不能据此承诺所有品牌手机兼容。测试结束已关闭模拟器，丢弃只读测试状态。

真机待验：一次性/重复提醒、重启和时间变化恢复、通知/精确闹钟拒绝、插件撤销、锁屏/静音/勿扰、音色缺失、停止播报、同刻多提醒、聊天音频焦点，以及多选下载/取消/存储不足/弱网/播放互斥。
