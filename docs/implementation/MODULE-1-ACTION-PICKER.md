# 模块1：手动选择内置动画

日期：2026-11-09；开发分支：feat/android-next-update。

## 使用与行为

启动桌宠后长按目标桌宠，选择“动作选择”；滚动列表展示该角色的内置动作（当前11段），可返回原菜单。菜单高度和宽度受安全显示区域限制，支持返回键和点击外部关闭。

选中动作后在当前位置播放一次，再恢复待机；移动素材只播放动作，不触发自动位移或转向。后续仍按原自由游走设置运行，不修改用户设置。不启动循环或动作锁定。

暂停/屏幕关闭期间拒绝切换并提示先继续；正在拖动时也拒绝。播放中暂停会保留进度，继续后接着播放。重新选择同一动作从头开始，不同动作立即替换。手动选择可终止抛掷并清零速度；点击、拖动、真实碰撞按原规则打断，不自动恢复被打断的动作。每个宠物独立选择，不切换其它宠物。

只接受已加载内置目录中的动作ID，不接收外部路径或新文件。动作名称来自现有素材文件名，缺失名称时使用本地化类别加序号。
