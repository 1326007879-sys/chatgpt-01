# 模块3：插件管理预备入口

日期：2026-11-09；开发分支：feat/android-next-update。

## 使用

主界面聊天入口下方增加“插件管理”按钮，不要求先启动桌宠或授予悬浮权限。点击打开独立页面，显示“暂未开放”“当前版本暂不支持外置插件。”以及功能预备说明。页面提供“返回主界面”按钮，系统返回沿用Activity默认导航。

页面可滚动，考虑系统安全区域，并提供中文/英文、系统明暗主题支持。Activity不对外导出，只通过应用内部显式Intent打开。

## 范围

只提供入口和说明页：不搜索、下载、安装或加载插件，不索取额外权限，不访问记忆、聊天记录、模型密钥或用户文件，不提供无实际作用的启停开关。尚未定义插件协议、签名校验或插件生命周期。

插件页面与动画选择/导入模块分离；未开始模块4语音输入。
