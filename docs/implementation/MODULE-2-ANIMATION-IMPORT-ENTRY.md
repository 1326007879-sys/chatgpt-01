# 模块2：导入新动画预备入口

日期：2026-11-09；开发分支：feat/android-next-update。

## 行为

启动桌宠，长按目标桌宠 → 动作选择。在动作列表顶部、提示下方增加“导入新动画（暂未开放）”。点击显示长提示：“动画导入暂未开放，后续将支持自定义添加动画。”

入口不启动文件选择器，不请求文件/存储权限，不读取、转换或保存文件，不切换当前动作，也不修改现有素材和动作列表。当前内置动作选择保持模块1的行为。

中文与英文提示均已添加。入口放在实际动作列表之前，方便小屏用户发现；菜单继续沿用已有滚动和安全区域限制。
