# 已知问题和验收边界

- 本版是待用户实测的插件原型，不是稳定正式版。不得将构建/JVM通过当作真实插件调用已通过。
- 主应用166项JVM、便签3项JVM、13项Python及lint、三个APK与设备测试APK构建已通过，协议及存储关键回归曾在CPU负载下重复3轮通过。
- 官方API35软件模拟器无KVM。两次测试出现系统服务异常、授权页启动超时。重测在1核/3GiB、系统启动稳定后仍停留启动画面。
- 隔离界面问题的临时测试授权已恢复。IPC设备运行器报Process crashed；日志为主应用failed to complete startup，被系统按ANR终止，用例尚未真正完成。系统电话进程也发生ANR、CPU压力接近100%。不能据此排除应用启动缺陷。
- 安装/卸载、授权、便签操作、真实Binder权限拒绝、超时、插件崩溃后的恢复及原有聊天稳定性仍需真机或稳定硬件加速模拟器验收。
- 第一版插件只支持手动字符串输入和文本/记录结果、插件私有存储及诊断范围。拒绝未知协议、未知数据权限及额外系统权限，不支持自动读取聊天、模型密钥或云记忆。
- 便签最多200条、每条1000字符、每页10条，明文JSON存于插件私有目录；无导出/云同步。卸载或清除插件数据会删除便签。
- 无在线插件市场、自动更新、自动模型工具调用、记忆系统或新动画压缩。95个可选动画包继续使用preview.3。
- 未验证全部品牌/系统版本；Debug签名升级兼容和数据迁移方案仍待完善。
