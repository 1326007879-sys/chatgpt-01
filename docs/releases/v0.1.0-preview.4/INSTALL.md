# 预览4安装与插件测试

这是待实测的开发预览版，Android 8.0/API26及以上。三个APK分别安装：

| 文件 | 用途 |
|---|---|
| chatgpt01-petai-0.1.0-preview.4-debug.apk | 主应用“AI 桌宠·预览4” |
| petai-notes-plugin-0.1.0-test-debug.apk | 本地便签插件 |
| petai-fault-plugin-0.1.0-test-debug.apk | 故障测试插件，可选，仅供测试 |

1. 先安装主应用。包名`io.github.chatgpt01.petai.preview4`，与预览3并存，不需要卸载旧版。
2. 通过系统文件管理器分别安装插件APK；也可在主应用“插件管理→安装插件APK”选择文件，按系统提示允许安装来源。
3. 打开手机应用列表中的“桌宠插件·本地便签”，在授权页找到“AI 桌宠·预览4”，点击允许访问。
4. 回到主应用“插件管理”，刷新→启用本地便签→同意权限范围→打开功能。
5. 输入便签并保存。查询关键词留空可查看列表，页码留空为1；选择某条记录编号后，点击删除便签。
6. 验证停用后不能调用。卸载通过系统确认，会删除插件自己的便签；主应用聊天数据保留。取消卸载时插件保持停用。

故障测试：安装并在故障插件自己的授权页允许“AI 桌宠·预览4”，再回主应用启用。依次尝试回声、模拟异常、超时、插件进程退出和越权探测。正常预期为超时/异常提示后主应用仍可使用，后续回声可恢复，越权探测显示UNAUTHORIZED。**这些预期尚未完成设备验收，请实测并反馈。**

先只测试便签即可，不必运行故障样例。测试超时/取消后，写入可能已经完成；先查询结果，不要反复点击保存。

主应用与旧版的模型、聊天及密钥不自动迁移。聊天需在预览4内重新配置；请避免同时启动多个版本的悬浮桌宠。
如果之前装过本地编译的同包名示例插件，签名可能不同；不要为升级直接卸载有重要便签的插件，卸载会清除数据。
本版为CI Debug签名，不承诺不同构建之间覆盖升级，固定发行签名尚未建立。
