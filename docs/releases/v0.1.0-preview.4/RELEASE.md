# v0.1.0-preview.4：插件原型实测版

供下载实测：真实设备端到端验收尚未完成，存在启动稳定性待定位问题。

- 独立APK插件，通过Binder/Messenger调用，不加载插件代码到主应用。
- 插件管理支持发现、授权、启用/停用、操作界面和系统安装/卸载入口。
- 本地便签：手动保存、分页查询和删除，数据保存在插件私有目录。
- 故障样例：异常、超时、进程退出及跨UID拒绝探测；另含协议不兼容与权限不支持的负面样例。
- 保留11段核心动画、独立动作包、键盘听写、中文/English、文字聊天及系统TTS。原preview.3的95个动作包继续兼容。

下载三个独立APK：主应用、便签插件，以及可选的故障测试插件。先安装主应用和便签插件，再打开插件自己的授权页允许“AI 桌宠·预览4”，最后回主应用刷新并启用。

主应用安装为“AI 桌宠·预览4”，与旧版并存，不读取旧版配置和聊天；不必卸载旧版。插件卸载会删除插件数据。

自动化：166项主应用JVM＋3项便签JVM、13项Python、lint和APK构建通过。**软件模拟器授权页启动超时，设备运行器因主应用启动ANR退出，未完成真实Binder验收。** 系统也有ANR及CPU拥塞，仍不能排除产品启动问题。

请先阅读INSTALL.md和KNOWN_ISSUES.md；校验及来源见SHA256SUMS.txt、SOURCE.json。
旧版发布和原作者仓库保留，未合并main或发布云环境。记忆系统、在线市场和压缩实验不在本版。
