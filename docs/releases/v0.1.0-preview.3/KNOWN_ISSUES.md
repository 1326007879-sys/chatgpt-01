# 已知限制与待验收

- 新版未完成真机端文件选择→导入→播放→删除的完整验收，界面设备测试仅编译通过。当前云环境无连接设备及KVM；此前软件模拟器启动ANR尚未定位，不能据构建成功声称稳定性已解决。
- 本版是开发预览版、Debug签名、独立包名；不能自动迁移旧版数据，也不保证未来覆盖升级。
- 需要停止悬浮桌宠后安装/删除动作，再重新启动。当前仅本地单动作包，不支持在线素材商店、合集安装、任意视频/GIF或新角色。
- 导入可能耗时；大文件需要足够存储空间。导入校验失败不会加入动作列表。哈希校验保证完整性，不等于作者签名认证。
- 只内置核心动作降低APK体积；全部扩展素材装齐后仍占约1.25GiB。未开始压缩格式实验。
- 键盘听写由输入法提供，部分输入法的语音功能可能需要网络。系统TTS音色和中文数据随设备而异。
- 悬浮权限、不同品牌后台限制、小屏、大字体、扩展动作透明窗口触摸范围、长时间运行、耗电发热仍待实机验证。
- 插件仍为预备入口；记忆系统、历史导出、云同步、连续语音通话和声音克隆不在本版范围。
