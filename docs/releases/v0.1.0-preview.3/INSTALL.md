# 安装与动作包使用

适用于Android 8.0/API26及以上。下载`chatgpt01-petai-0.1.0-preview.3-debug.apk`并安装，不要下载Source code来安装。
启动器名称“AI 桌宠·预览3”，包名`io.github.chatgpt01.petai.preview3`。

本版采用独立测试身份，与旧预览版并存，不必卸载旧版；不自动读取旧版模型设置、聊天记录或密钥。模型配置需在新应用内单独设置。
请避免同时启动多个版本的悬浮桌宠，以免混淆。

## 动画按需安装

APK内置11段核心动作。其余95个动作在同一Release分别下载，中文名称与下载链接见`ANIMATIONS.md`。

1. 只下载想要的`.petanim`文件，不用下载全部动作。
2. 打开应用的“动画管理”，先停止悬浮桌宠；文字聊天不受影响。
3. 点击“导入新动画”，在系统文件选择器中选中刚下载的动作包。
4. 等待“安装成功”，重新启动桌宠，长按桌宠→动作选择→已安装的扩展动作。
5. 删除扩展动作前先停止桌宠，在管理页确认删除。原始下载文件不会自动删除，内置动作不可删除。

重复动作不会重复占空间；更换素材版本需先删除旧动作再导入。仅支持规范的单动作包，不能直接导入任意视频或GIF。
全部扩展动作仍约1.25GiB；本版通过按需安装减小初次安装包，没有改变无损帧压缩格式。下载文件和安装后的素材会分别占用空间。

## 语音与语言

消息输入框使用手机输入法的麦克风听写，检查后手动发送。本应用不再打开独立识别窗口；输入法需自行具备可用的语音服务。
首页可切换简体中文/English；输入法、系统页面及模型原文不随应用自动翻译。
回复朗读和音色选择仍依赖设备的TTS引擎及已安装语言数据。

本版为Debug签名，固定签名与升级方案尚未完成。不要为了安装而清除或卸载有重要数据的旧应用。
卸载/清除本版数据会删除本版配置、聊天记录、密钥和导入动作；无历史导出或云同步功能。

附件`SHA256SUMS.txt`提供APK、动作包和说明文件的校验值。Windows可用Get-FileHash，Linux可用sha256sum。
