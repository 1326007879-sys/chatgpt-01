- 新增4项设备集成测试已编译，但没有取得设备通过结果；JVM和构建通过不等于设备界面通过。

- 本包为独立测试应用，不自动读取旧版数据；Debug签名不保证跨构建覆盖升级。
- 动画导入和插件管理只有预备入口；无连续语音通话、唤醒词、声音克隆或记忆系统。
