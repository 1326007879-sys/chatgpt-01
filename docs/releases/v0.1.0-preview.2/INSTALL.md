# 安装与测试

下载本版APK而不是Source code压缩包。Android 8.0及以上，允许下载所用浏览器/文件管理器安装应用后打开“AI 桌宠·预览”。

本包 `io.github.chatgpt01.petai.preview` 与旧包 `io.github.chatgpt01.petai` 并存，旧版数据不会自动迁移，也无需卸载旧版。避免同时启动两版悬浮桌宠，以免混淆。

1. 主界面进入“和主宠聊天”，在模型设置填写服务地址、模型和自己的密钥。新包需要单独配置；密钥只在应用内输入。
2. 先验证文字聊天，再测试语音输入；识别结果只进入草稿，请检查后发送。无识别服务时可继续键盘输入。
3. 聊天页“语音设置”：选择系统已安装音色，点击试听。需要自动朗读时开启开关；默认关闭。
4. 授予悬浮权限后启动桌宠，长按→动作选择；选一个动作，检查播放完成恢复待机。
5. 动画导入和插件管理均只是预备入口，显示暂未开放。

系统可能没有语音识别或中文TTS服务；可在设备系统设置安装相关服务及语言数据，再重新打开聊天。音色和识别服务可能联网，不保证离线工作。

当前有ANR待定位，请优先使用独立测试设备或硬件加速模拟器。出现无响应/闪退时先保存截图和日志，不要通过清除数据来掩盖问题。

本版仍是临时Debug签名，不保证未来同包名构建能覆盖升级。卸载或清除本测试包的数据会删除其本地配置、密钥和聊天历史；没有导出/云同步功能。

文件校验：Linux使用 sha256sum -c SHA256SUMS.txt；Windows可使用Get-FileHash计算APK的SHA256并与附件核对。
