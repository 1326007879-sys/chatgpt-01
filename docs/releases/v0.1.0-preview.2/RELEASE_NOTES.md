# AI 桌宠 v0.1.0-preview.2 · 六模块验收版

本版供下载测试，**不是稳定正式版**。已知启动/无响应问题仍待定位，真实录音、TTS播放和音色听感尚未完成设备验收。

## 新增内容

1. 长按桌宠 → 动作选择：列出11段内置动作，原地播放一次后恢复待机；暂停时先继续，点击/拖动/碰撞可打断。
2. 动画导入预备入口：只提示暂未开放，不实际导入文件。
3. 主界面插件管理预备页：不加载或安装外置插件。
4. 语音输入：调用设备识别服务，将结果追加到草稿，由用户确认后发送；无服务时仍可打字。
5. 回复朗读：支持手动朗读与停止；自动朗读默认关闭，可在“语音设置”开启，只读新完成的回复。
6. 系统音色：支持试听、选择和保存；可用音色由设备引擎决定。

## 下载安装

在 Assets 下载 `chatgpt01-petai-0.1.0-preview.2-debug.apk`；Android 8.0及以上。

**本次为独立安装测试包**：启动器名称“AI 桌宠·预览”，包名 `io.github.chatgpt01.petai.preview`，与旧版并存，不覆盖旧版数据。模型配置、密钥和历史不自动迁移，需要在新版里单独配置。不要为了安装本版卸载旧版。

APK仍使用CI临时Debug签名，不承诺未来各次测试构建之间的覆盖升级。附件SOURCE.json记录源码提交、构建参数和实际校验值；安装与反馈步骤见INSTALL.md。

## 验证与限制

- 本地152项安卓JVM测试、6项素材测试通过，ruff通过；lint无错误，仍有16项警告及7项提示。
- GitHub Actions会对本次发布源码和独立安装参数重新执行检查、构建与签名/附件校验。
- 软件模拟器曾安装成功，但界面测试进程因启动ANR退出，系统组件同时有DeadSystemException和Quickstep无响应；不能认定界面和运行稳定性通过，也不能完全排除应用问题。
- 麦克风、识别服务、中文语音数据、音色与联网需求依设备而异。本应用不保存录音，识别或TTS服务可能联网处理内容；不会向语音引擎提供模型API Key。
- 语音输入不是持续语音通话；没有唤醒词、声音克隆或内置角色配音。记忆系统和真正的插件加载均未接入。
- 内置角色素材有个人、非商业使用限制，代码MIT许可不等于素材可商用。

出现无响应时请记录操作步骤、手机/模拟器型号、Android版本、是否开启硬件加速，并提供脱敏截图或日志；不要提交密钥。
