# AI 桌宠 v0.1.0-preview.1 · 开发预览版

这是独立安卓项目的首个开发预览版，供试用和反馈，**不是稳定正式版**。

## 本版功能

- 悬浮桌宠、拖动、抛掷、碰撞与伙伴互动。
- 主界面和长按菜单进入同一个主宠聊天会话。
- OpenAI Chat Completions 兼容 HTTPS 流式文字对话，支持停止和可重试回复。
- 模型配置、按服务地址隔离的密钥存储、本地历史和中断恢复。

## 安装

下载 `chatgpt01-petai-0.1.0-preview.1-debug.apk`，在 Android 8.0 及以上手机安装。版本为 `0.1.0-preview.1`（code 1），应用包名 `io.github.chatgpt01.petai`，与原版独立。
打开“AI 桌宠” → “和主宠聊天” → “模型设置”。服务地址、模型和 API Key 按服务商文档填写；密钥仅在应用内输入。
聊天无需先授予悬浮权限；悬浮宠物需另外在系统中授权。详细步骤见 INSTALL.md。
