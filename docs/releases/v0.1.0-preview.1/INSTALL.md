# 安装与首次使用

适用 Android 8.0/API26 及以上；本包为 Debug 开发预览，不是商店正式版。
包名 io.github.chatgpt01.petai，版本0.1.0-preview.1/code1。新包与旧版深深桌宠包名不同，不覆盖其私有数据，也不自动导入旧历史。

1. 下载 chatgpt01-petai-0.1.0-preview.1-debug.apk；可先用 SHA256SUMS.txt 校验文件。
2. 用手机文件管理器打开，按 Android 系统提示允许该来源安装。
3. 打开“AI 桌宠”，点击“和主宠聊天”。此步骤不要求悬浮权限。
4. 打开“模型设置”，填写兼容服务的 HTTPS API 根地址、模型名称和 API Key；根地址不含 /chat/completions。
5. 保存后发送消息。若提示未配置或保存失败，输入会保留；不要反复更换服务并期待沿用其他服务密钥。
6. 可停止生成或重试最近一条可重试的未完成回复；主界面与宠物菜单进入同一会话。
7. 如需悬浮宠物，返回主界面授予“显示在其他应用上层”权限并启动，长按宠物可再次进入聊天。

密钥只在应用内输入，不上传截图、不提交 Issue 或代码仓库。密钥使用 Android Keystore 支持的加密存储；聊天历史在应用私有目录本地保存。
当前聊天页主要为中文、纯文本，可选择复制；不提供语音和云同步。普通返回不会主动停止请求，系统结束进程后回复可能中断，不自动重发。
未发送草稿不跨进程保存。未来正式版签名及数据迁移方案未确定；当前包不是正式升级兼容承诺。

Windows 校验示例：Get-FileHash .\chatgpt01-petai-0.1.0-preview.1-debug.apk -Algorithm SHA256
Linux 校验：sha256sum -c SHA256SUMS.txt
macOS 校验：shasum -a 256 -c SHA256SUMS.txt

反馈时注明手机型号、Android版本、版本号、复现步骤和错误文字；不要附带密钥、私人聊天内容或未打码截图。
