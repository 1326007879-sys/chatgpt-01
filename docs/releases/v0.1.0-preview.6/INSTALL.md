# 预览6安装与测试

本次为提醒诊断测试预发布，不是稳定正式版。

1. 下载chatgpt01-petai-0.1.0-preview.6-debug.apk，Android8.0/API26及以上可尝试安装。
2. 安装后打开“AI 桌宠·预览6”，包名io.github.chatgpt01.petai.preview6。它与预览5并存，不必卸载旧版；聊天、模型配置、提醒、动作和插件配对不会自动迁移。避免同时运行两个版本的悬浮桌宠。
3. 首页进入“便签与提醒”，允许通知，按需允许精确闹钟。输入测试事项，明确选日期和时间，先建立2分钟后、不朗读的提醒，再回手机桌面等候。检查通知栏和提醒页的调度/接收/通知时间。
4. 文字提醒通过后，用设备系统TTS验证语音播报。先在音色设置试听，再创建勾选朗读的新提醒。静音、勿扰、锁屏及后台限制会影响播报；不要把没有声音直接等同于没有通知。
5. 如果到点未提醒，记录设备、Android版本、设置时间、等待时长、通知/精确闹钟权限、诊断时间和错误提示。原提醒故障尚未定位，本版增加诊断，不承诺已经修复。非精确闹钟可能被系统延迟。

## 本版没有公开提供新离线音色

系统TTS可用性依赖设备已有引擎及语言数据。源码包含独立离线语音接入，但本次不附引擎APK、模型或音色包，不能直接使用新卡通音色；相关设置不代表资源已经随安装包提供。未安装引擎时出现不可用提示是预期边界，不需要填写模型API Key来测试提醒。

## 动画与便签

沿用11段核心动画及在线/本地独立动作安装；安装前停止悬浮桌宠。主应用可以独立创建提醒，无需便签插件。

如需便签，保留已经安装的旧便签插件，给“AI 桌宠·预览6”重新授权，再在主应用插件管理刷新和启用。没有插件时可从预览5的Release附件下载原插件；本次不重新签名发布旧插件，避免损坏已有便签数据。
