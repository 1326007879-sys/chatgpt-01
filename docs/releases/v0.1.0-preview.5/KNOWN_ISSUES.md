# 预览5已知问题与验证边界

- 这是开发预发布，不是稳定正式版。187项主应用JVM、3项便签JVM、13项Python与Ruff、三个模块lint、主应用/插件/设备测试包构建通过。
- 同功能开发构建在官方API35只读软件模拟器通过5项用例：真实精确闹钟唤醒到通知、通知投递/清理、私有组件、页面重建编辑状态、动画目录多选。模拟器无KVM，启动和首次安装较慢。
- 上述设备测试针对独立development身份和本地签名；本次preview5包名与CI签名不同，不能将其当作最终发布APK全量设备验收通过。
- 真实重启、跨品牌长期后台、真实语音听感、完整插件配对/撤销链路和Android联网下载安装完整链路仍需用户实测。
- 提醒依赖通知权限、系统闹钟和电池限制。不保证各品牌绝对准点；强制停止后需重新打开。迟到超过15分钟显示错过提醒，不自动补播；每日重复不批量补播多天。
- TTS使用设备引擎与音色数据，无声音克隆、自定义模型或外置音色插件；锁屏/静音/勿扰及后台启动限制会影响自动播报，通知保留手动朗读入口。
- 提醒最多200条（含已处理记录），每条1000字符，明文JSON在主应用私有目录；无导出或云备份。便签是独立数据，删除原便签不会删除提醒。
- 动画目录固定为preview3的95项，刷新仅校验该可信版本；不会自动出现未来动作。安装前需停止悬浮宠物；下载失败可完整重试，无后台续传或新压缩算法。
- 插件协议v1权限不扩大；提醒创建在宿主确认，不是插件自动调用闹钟接口。无自然语言时间解析、云记忆、在线插件市场或自动升级。
- 便签与故障插件附件沿用预览4原包和签名；主应用Debug签名不保证跨构建覆盖升级；preview5与旧版数据和配对不自动迁移。旧版Release和附件保留。
