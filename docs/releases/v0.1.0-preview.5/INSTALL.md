# 预览5安装与测试

Android 8.0/API26及以上。下载chatgpt01-petai-0.1.0-preview.5-debug.apk，打开安装“AI 桌宠·预览5”。包名io.github.chatgpt01.petai.preview5，与预览4及开发测试版并存；不用卸载旧版，聊天、密钥、已安装动作和插件配对不会自动迁移。避免同时启动多个版本的悬浮桌宠。

## 提醒与播报

1. 首页→便签与提醒，允许通知；按需允许精确闹钟。不允许精确闹钟时会使用近似调度，可能延迟。
2. 输入事项，选择日期和24小时制时间，可选每天重复和语音播报，再保存；在列表编辑、取消或删除。
3. 也可从便签插件返回的记录下选择“为此记录设置提醒”。提醒保存独立副本，删除便签不会删除提醒。
4. 回复/提醒朗读使用设备系统TTS。聊天页的语音设置可选系统音色；本版不含自定义音色模型或音色插件。
5. 锁屏、静音和勿扰时不自动播报；后台限制可能阻止语音服务启动。文字通知仍可查看，解锁后可点击通知中的朗读，播放通知提供停止按钮。系统音色可能需要联网或安装语言数据。

## 在线动画

动画管理→在线动画→停止悬浮桌宠→多选需要的动作→下载安装。默认11段核心；95段可选动作只下载所选项，目录来自预览3固定资源。支持取消和失败重试，本地文件导入入口保留。GitHub访问较慢时可手动下载.petanim后导入；没有断点续传。

## 可选便签插件

主应用可独立创建提醒。若使用便签，另装petai-notes-plugin-0.1.0-test-debug.apk。打开“桌宠插件·本地便签”，允许“AI 桌宠·预览5”访问；回主应用插件管理刷新→启用→确认权限→打开功能。故障插件仅供开发测试，可不安装。

本版附件沿用预览4的插件原包和签名。已安装预览4便签插件时直接保留，只需授权新宿主；如果安装的是本地编译的同包名插件，签名可能不同，不能保证覆盖安装。不要直接卸载重要便签；卸载/清除插件数据会删除便签。停用插件会撤销宿主关联提醒，插件内部单方面撤销配对不一定能被宿主即时感知；请在宿主取消提醒或停用插件。

本版为CI Debug签名，未来版本的固定签名及数据迁移尚待完善。卸载主应用会删除其聊天、提醒及扩展动作；不会删除独立旧版应用。反馈请注明版本、设备、系统、权限状态、失败步骤，不要提交密钥或私人便签。
